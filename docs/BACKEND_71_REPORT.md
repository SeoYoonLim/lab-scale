# 71차: 기간 지정 원인 분석 정확도 개선 (2026-11-18)

**결론**: 기간을 붙인 단일 종목 원인 질문을 LLM 없이 코드로 답한다. 대상은 "셀트리온 지난주 급등 이유", "카카오 한 달 동안 왜 떨어졌어?", "최근 N거래일", "지난달" 같은 질문이다.

- 종목 수익률과 상장 시장 지수 수익률을 같은 두 날짜로 따로 계산한다. 질문의 전제(급등·하락)는 실제 등락과 대조한다.
- 원인 근거는 기간 안, 시세 기준 시점 전 기사·공시만 쓴다.
- 독립 SQL 대조 2,800건(350종목 × 8가지 기간)에서 불일치 0건이다.
- 실데이터 답 13건 자동 감사에서 완료 판정 7개 항목 위반 0건이다.

| 완료 판정(추가 조건 F) | 결과 | 근거 |
| --- | --- | --- |
| 종목명 불일치 | 0건 | 5.3 감사(13건) |
| 수익률 계산 오류 | 0건 | 5.2 독립 SQL 2,800건 + 5.3 감사 |
| 시장 지수 혼동 | 0건 | 5.2(코스피·코스닥 매핑, 종목 줄에 지수 수치 없음) + 5.3 |
| 기준일 위반 | 0건 | 5.3(뉴스 게시 시각이 출발 종가 뒤~기준일 마감 전) + 통합 테스트 |
| 근거 출처 누락 | 0건 | 5.3(목록 항목마다 날짜·출처) |
| 근거 없는 인과관계 생성 | 0건 | 5.3(인과 표현 금지어 검사, "단정할 수 없음/특정할 수 없음" 표기) |
| 데이터 지연 은폐 | 0건 | 5.3(지연 줄), 미완료 기간·중간 누락 표기 |

이 판정은 **기간 원인 코드 경로**에 대한 것이다. 이 경로 밖에 남는 답(3개월 초과 기간 원인 질문, 환율 LLM 답)은 7절에 "시연 사용 불가"로 따로 적었다.

## 1. 발견 원인

70차 실검증(docs/FINAL_INTEGRATION_AUDIT_70.md 5.2의 2b·10)에서 문제가 드러났다. 이번에 수정 전 코드(`f43d7d6` worktree)로 그대로 재현했다(4절).

1. 69차는 "오늘·어제"만 원인 코드 경로로 받았다(`answer_cause._CAUSE_ONLY_PERIODS`). "지난주·한 달·지난달·N거래일" 질문은 LLM 경로였다.
2. LLM 경로에서는 69차 필터가 미래 기사를 막았다. 그러나 다음 세 가지는 LLM이 맡았다.
   - 전제 확인
   - 종목·지수 주어 구분
   - "원인 특정 불가" 안내
   그 결과는 이랬다.
   - 셀트리온: '급등' 전제를 바로잡지 않았다(실제 -0.71%).
   - 카카오: 코스피 -16.31%를 "최근 23거래일간 … 코스피는 -16.31%의 위아래폭"처럼 썼고, "인적분할 발표로 … 하락한 것으로 보입니다"라고 근거 없는 인과를 냈다.
3. 기간 표현을 해석하지 못하면(`period_parser.parse_period`가 None) 69차 원인 단독 경로가 "최근 5거래일"로 바꿔 답했다. 예: "다음 주 왜 올랐어?", "0거래일", "13월에".
4. 질문의 종목을 못 찾으면 직전 리포트 종목을 이어받았다. 그래서 오타(`삼송전자`)·그룹명(`현대`)이 직전 종목(예: 카카오)의 수치로 답해질 수 있었다(69차 경로 포함).
5. 원인 후보에 주가·거래 동향 기사가 섞였다("거래대금 …, 상승 마감 전 흐름", "카카오 주가 3만원대 이탈"). 움직임을 묘사한 기사이지 원인이 아니다.
6. (추가 조건 D 점검 중 발견) 환율 답이 11-02 값을 "현재 환율은 약 1,325.52원에 거래되고 있습니다"로 썼다. 기준일·지연 표시도 없었다(`answer_basis.ensure_basis`는 주가만 처리).

## 3. 규칙

### 3.1 기간 해석

| 질문 표현 | 창 |
| --- | --- |
| 지난주·이번 주·지난달·이번 달·한 달·N주·N일·N개월 | 질문이 가리키는 달력 범위(`period_parser`). 그 안의 **KRX 거래일**(`krx_calendar.trading_days`, 휴장일 제외)로 계산 |
| 최근·지난 N거래일 | 시세 기준일(마지막 저장 거래일)부터 KRX 거래일로 N일. 68·69차 "최근 5거래일" 정의와 같다 |
| 3개월 초과(달력 93일, 63거래일 넘음: 4개월·100거래일·1년·올해) | 이 경로가 아니다. 기존 LLM 경로(+69차 기준 시점 필터) |
| 미래("다음 주", "내일") | 계산하지 않고 "아직 오지 않은 기간"이라고 답한다. 전망 질문을 안내한다 |
| 0 기간("0거래일", "지난 0일") | 계산할 수 있는 기간이 아니라고 답한다 |
| 해석 불가 연·월("13월에", "2025년에") | 다른 기간으로 바꿔 답하지 않는다고 밝힌다 |

- 출발점은 창 첫 거래일의 **직전 저장 거래일 종가**다. 끝은 창 안 마지막 저장 거래일 종가다.
- 요청 범위 끝까지 시세가 없으면 빠진 거래일을 날짜로 쓴다. "끝나지 않은 기간이라 이 수치는 기간 전체 등락이 아닙니다"라고 밝힌다.
- 중간에 빠진 거래일은 날짜로 쓴다. 값을 보간하지 않는다.
- 직전 거래일 시세가 없으면 그 전 저장일을 출발점으로 쓰고, 그 사실을 밝힌다.
- 시세가 기간 중간에 시작하는 경우(상장·수집 시작)는 저장 시세 시작일부터 계산한다. "요청 기간 전체의 등락이 아닙니다"라고 밝힌다.
- 창 안 저장 시세가 하나도 없으면(예: 이번 주, 시세는 지난주까지) 계산하지 않는다. "없는 시세를 추정해 채우지 않습니다"라고 쓴다.

### 3.2 종목·지수 수익률

- 종목: `(끝 종가 / 출발 종가 - 1) × 100`, 소수 둘째 자리. 저장 종가만 쓴다.
- 지수: 종목 `market`이 KOSPI면 코스피(KS11), KOSDAQ·KOSDAQ GLOBAL이면 코스닥(KQ11)이다(`market_tool.index_code_for_market`).
  - **종목과 같은 두 날짜**의 지수 종가로 따로 계산한다. 둘 중 하나라도 없으면 비교하지 않고 그렇다고 쓴다.
- ETF(`market` 없음)는 지수와 비교하지 않는다. "ETF 자체의 등락이며 구성 종목이나 지수의 등락이 아닙니다"라고 쓴다.
- 문장은 주어를 붙여 줄을 나눈다.
  - `- 카카오(종목) 주가: …, -0.47%.`
  - `- 같은 기간 코스피 지수: …, -5.74%. 카카오(종목) 수익률은 코스피 지수보다 5.27%p 높았습니다.`
- 다음 문장을 항상 붙인다: "지수 비교는 참고입니다. … 같은 방향(또는 반대 방향)으로 움직였다는 사실만으로 원인을 판단하지 않습니다."

### 3.3 전제 확인

- 질문의 '급등·급락·올랐다·내렸다(하락 이유 등)'를 실제 기간 등락과 대조한다.
- 반대 방향이면 "질문의 전제와 다릅니다: 질문은 '급등'이라고 하셨지만, 셀트리온 주가는 이 기간 -0.71%로 내렸습니다"라고 쓴다.
- 같은 방향이면 "같은 방향입니다"라고만 쓴다. 강도를 부풀리지 않는다.

### 3.4 뉴스·공시 근거

- 뉴스는 **출발일 장 마감 뒤 ~ 기준일 장 마감 전**만 쓴다. 출발 종가에 이미 반영된 기사와 기준일 뒤 기사는 원인 후보가 아니다.
- 69차 규칙은 그대로다.
  - 기준일 당일 장 마감 뒤 기사는 건수만 센다.
  - 당일 KST 자정 기사(시각 모름)는 건수만 센다.
  - 기준일 다음 날 이후 기사는 건수만 센다.
- 공시는 접수일만 있다(전부 KST 자정). 그래서 **출발일 다음 날 ~ 기준일 전날 접수분**만 쓴다. 출발일·기준일 당일 접수분은 장 마감 전후를 알 수 없어 뺀다.
- 종목 정합성은 이 종목에 연결된 기사(`company_id`)이고, 제목에 종목명이 있어야 한다(68차 `evidence_news`). `is_relevant=false`는 제외한다. ETF는 더 긴 다른 ETF 이름을 제외한다.
- 주가·거래 동향 기사(`is_price_report`)는 원인 후보에서 빼고 건수만 밝힌다.
- 근거를 나열할 때는 "주가 변동의 직접 원인이라고 단정할 수는 없습니다"를 붙인다. 근거가 없으면 "움직임의 원인을 특정할 수 없습니다"라고 쓴다.
- 기간 경로는 뉴스·공시를 최대 5건씩 보인다. 더 있으면 "제목에 종목명이 있는 기사 N건 중 5건"이라고 쓴다.

### 4.1 10번: 셀트리온이 지난주 급등한 이유가 뭐야?

수정 전(LLM 경로)

> 셀트리온은 최근 4일 동안 209,500원에서 거래되었습니다. 4거래일 동안 -0.71% 하락했습니다.
> 뉴스·공시 근거: 주식 시세가 올라가는데 영향을 미친 근거 중 하나는 호주에서 자가면역질환 치료제 '비세큐마'의 품목허가를 신청했을 가능성이 있어요.

문제

- '급등' 전제를 바로잡지 않았다.
- 실제 하락인데 "시세가 올라가는데 영향을 미친 근거"라고 썼다.
- 분석 기간과 지수 비교가 없다.

## 8. 남아 있는 문제

1. 3개월 초과 기간 원인 질문, 두 종목 원인 질문은 LLM 경로다. 미래 기사는 69차 필터가 막지만 전제·주어·인과 표현 검증은 코드가 하지 않는다.
2. 환율 답 본문은 LLM이 쓴다. 수치를 기간에 잘못 붙이는 오류가 확인됐다(7절). 환율 질문을 코드 답으로 바꾸는 것이 다음 후보다.
3. 근거 목록이 같은 사건 기사 여러 건으로 채워질 수 있다. 예: 셀트리온 '비세큐마' 기사 5건. 사건 단위로 묶으면 더 읽기 좋다.
4. 시세 기사 판별(`PRICE_REPORT_RE`)은 제목 규칙이다. "현 주가 저평가"처럼 숫자 없는 표현은 통과시키도록 좁게 잡았다. 그래서 놓치는 시세 기사가 있을 수 있다(그 경우에도 "단정할 수 없다"는 표기는 붙는다).
5. 실행 중인 백엔드(09:16 시작)는 69·71차 코드가 반영되지 않은 상태다. 재시작은 사용자 승인 사항이다.
6. 저장 시세가 11-12, 환율이 11-02에 멈춰 있다. 갱신은 승인 사항이다.
