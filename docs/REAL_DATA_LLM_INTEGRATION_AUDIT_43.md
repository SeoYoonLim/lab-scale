## 4. KRX·NXT·FinanceDataReader 종가 비교 — 원인 확인, 공식 1차 문서 미확보

### 4-1. FinanceDataReader의 실제 원천

`fdr.DataReader('005930')`는 소스를 지정하지 않은 6자리 국내 코드를 **네이버 일봉**(`NaverDailyReader`, `https://fchart.stock.naver.com/sise.nhn?timeframe=day&requestType=0`)으로 읽는다(설치된 FinanceDataReader 0.9.202 `data.py`: "Naver is default source for KRX stocks").
KRX 소스(`KRX:005930`)는 KRX 데이터 포털 응답이 JSON이 아니어서 실패한다(포털 직접 호출은 HTTP 400, 로그인 필요로 추정). 지수 KS11·KQ11은 별도 경로(`KrxIndexReaderCache`, GitHub `FinanceData/fdr_krx_data_cache`)다.

- KRX 애프터마켓은 **2026-09-14부터** 16:00~20:00 접속매매로 운영되며, **ETF·ETN은 거래 대상에서 제외**된다([한국경제 2026-09-14](https://www.hankyung.com/article/2026091442517)).
- NXT 애프터마켓은 15:40에 개장하고 약 600종목이 대상이다. 같은 기사에 **"애프터마켓 종가는 공식 종가로 인정되지 않는다"**는 문장이 있다([머니투데이 2026-09-13](https://www.mt.co.kr/stock/2026/09/13/2026091115014844655)).
- KRX 1차 공지·규정 문서는 확보하지 못했다(데이터 포털 접근 불가). 그래서 **"신뢰할 수 있는 보도와 원천 내부 대조로 확인, 1차 문서 미확보"**로 둔다.

### 4-4. 결론과 영향

- 2026-09-14 이후 **주식**의 네이버 일봉 `closePrice`는 공식 종가(정규장 15:30 종가 = 다음 날 기준가)가 아니라 **장 종료(20:00) 시점의 마지막 체결가**다.
  - 수집 시각이 15:40~20:00이면 그 사이의 중간값이 저장된다.
  - 개발 DB의 11-03 행은 19:45에 저장돼 거래량도 최종값보다 적다(삼성전자 13,338,444 vs 13,391,670).
- 시가·고가·저가는 정규장 값이고 종가만 바뀐다. 거래량도 정규장 이후 거래분이 조금 더해진다(통합 거래량과는 다름).
- 영향 범위: 1일 등락률(예: 삼성전자 11-11 저장 기준 +4.41% vs 공식 +3.57%), 모든 N일 수익률·이동평균·전망 신호·백테스트·포트폴리오 평가, 리서치 답.
  ETF는 영향이 없다.
- TIGER 200 11-02(+1.42%)는 원천의 전일 대비와도 일치하고 분배락도 아니다. 원천 자체는 일관되며, 외부 독립 대조 근거가 없어 **추가 확인 필요**로 둔다(데이터 수정 안 함).
- **수정하지 않았다**: 저장 가격 덮어쓰기·보정, 수집기 변경 모두 하지 않았다. 아래 6.1의 결정이 먼저다.
