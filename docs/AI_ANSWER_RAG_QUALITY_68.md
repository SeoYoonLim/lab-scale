**정밀도 확인(눈으로 전수 확인)**

## 9. 실제 DB·Ollama 검증과 데이터 불변

- 모든 실DB 확인은 `default_transaction_read_only=on` 연결이다. 리포트는 `save_report=False`로 저장하지 않았다.
- 임베딩은 Ollama `bge-m3`로 했다. 채팅 경로 표본 3건에는 `llama3.1:8b`를 썼다.
- Ollama 설정은 바꾸지 않았고, 재시작하지도 않았다.
- 개발 DB 23개 표 행 수·md5가 68차 시작 전 스냅샷(19:39)과 모두 같다.
  - `pg_stat_user_tables` 누적값도 그 전과 같다. 66차 임베딩, 사용자 채팅 4건은 앞서 있던 값이다.
  - Alembic `c7e2a9f4d158`, `stock_price_session` 없음
- 새로 만든 것: 평가용 DB `ai_investment_eval68`(남겨 둠), 스크래치 worktree(수정 전 기준선)
