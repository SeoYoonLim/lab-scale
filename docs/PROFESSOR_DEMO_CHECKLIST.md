### 질문할 때 주의

- **"5일 수익률"이 아니라 "최근 5거래일 수익률"이라고 묻는다.** "5일"은 달력 5일로 읽혀 2거래일(-7.62%)로 답한다(답에 "2거래일간"이라고 정확히 밝히지만 질문 의도와 다르다). 영어도 "5-day return" 대신 "over the last 5 trading days"를 쓴다.
- 질문 8·9·12는 이전 답에 이어 묻는 질문이다. 새 프런트에서는 "이 답변에 이어서 묻기" 토글을 켜야 이어진다(기본 꺼짐).
- '오늘' 질문은 저장된 마지막 거래일 기준으로 답하고 그 차이를 먼저 말한다. 시연 중 "왜 오늘 값이 아니냐"고 물으면 공식 종가 확정(18시 전후) 뒤에 수집한다고 설명한다.

## 4. 각 답에서 확인할 항목

- 종목명·종목코드가 질문 종목과 같은가
- 시작일·종료일·거래일 수가 적혀 있고 수익률과 맞는가
- 지수 수익률과 종목 수익률을 따로 적었는가
- 하루 변동률과 기간 수익률을 구분했는가
- 인용한 기사·공시가 각주로 나오고 링크가 열리는가, 날짜가 시세 기준일 이전인가
- 데이터 지연("1영업일 이전 시세")을 밝혔는가
- 전망에 "확정 예측이 아님"이 있고 매수·매도를 권하지 않는가

## 5. 장애 대응

### 백엔드가 응답하지 않을 때
1. `curl http://127.0.0.1:8000/api/health`로 상태를 본다.
2. 포트 8000 프로세스 확인: PowerShell `Get-NetTCPConnection -LocalPort 8000 -State Listen`
3. 재시작(백엔드 폴더): `.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000`
4. `degraded`이고 `db.ok=false`면 `docker start ai_investment_db` 뒤 10초 기다렸다가 다시 확인한다.

### 프런트가 열리지 않을 때
프런트 폴더에서 `npx vite --host 127.0.0.1 --port 5173 --strictPort`. `.env.local`이 없으면 mock 모드가 되므로 `VITE_USE_MOCK=false`를 먼저 확인한다.

### Ollama가 실패할 때(리허설에서 확인)
- 증상: LLM 경로 질문(예: "삼성전자 HBM 사업 경쟁력을 설명해 줘.")이 약 2초 뒤 "응답 생성이 지연되어 답변을 만들지 못했습니다. 잠시 후 다시 시도해주세요."로 끝난다. `/api/health`의 `ollama.ok`가 false다.
- **코드 경로 질문(3~13번, 수익률·원인·전망·ETF·환율)은 Ollama 없이도 그대로 답한다.** 시연을 이 질문들로 이어간다.
- 복구: Ollama 앱을 다시 켜고 `curl http://127.0.0.1:13434/api/tags`로 확인한 뒤 질문 1번으로 예열한다. 모델을 새로 내려받거나 바꾸지 않는다.

### 데이터가 오래됐다고 나올 때
답과 화면이 지연을 스스로 밝힌다. 갱신은 DB 쓰기라 발표 전 별도 승인을 받고, 백업 후 `python -m scripts.refresh_data`를 실행한다(약 10분).

## 6. 시연 제한 사항(질문 받으면 설명)

- ETF 구성종목은 2026-10-30 기준이다(KODEX·TIGER 38개만 지원).
- 분기 실적은 2026년 반기까지다(3분기 보고서 미수집).
- 업종(sector) 데이터가 없어 업종 집중도는 계산하지 않는다.
- 해외 종목은 지원하지 않는다.
- 일봉 원천(FinanceDataReader·네이버)은 비공식 래퍼라 학습·시연 내부 사용으로 한정한다.
- 분봉 데이터·분봉 자동화는 시연 범위가 아니다.
