# 최종 답변 품질 보완 (2026-11-23)

브랜치 `fix/final-answer-quality-followup-20261123` (기준 `origin/main` 5577657 = c46cb4d + README 문서 PR #21).
브라우저 테스트에서 나온 답변 품질 문제 5개를 고쳤다. 새 기능·API 필드·DB 스키마 변경은 없다.

## 1. 기업 직접 원인과 업종·시장 상황 구분

- 원인: 원인 답의 기사는 "그 종목에 연결되고 제목에 이름이 있는 기사"를 모두 같은 근거로 썼다. 실제로는 코스피 시황, 여러 기업을 함께 다룬 기사
  ("삼성전자·SK하이닉스 현금 329조"), ETF 리밸런싱 기사가 섞였다. "약세인 이유는?"은 원인 질문으로 잡히지 않아 LLM 경로로 갔고, 모델이
  업종 기사를 SK하이닉스의 원인처럼 썼다.
- 수정: `app/evidence_scope.py`가 제목 + 본문 요약으로 기사를 기업 직접 / 업종·산업 / 시장 / 관련성 미확인으로 나눈다(코드 규칙, LLM 없음).
  다른 등록 기업과 나란히 나오거나(·, /), "삼전닉스·투톱"처럼 묶었거나, 시황·업종 낱말이 있는데 이 기업이 제목 맨 앞 주어가 아니면 직접 기사가 아니다.
  본문 요약에 이 기업이 없으면 관련성 미확인이다. 공시는 언제나 직접 근거다.
  - 코드 원인 경로(`answer_cause.collect`·`evidence_lines`): 직접 기사·공시만 원인 후보 목록에, 업종·시장 기사는 `[업종·산업]`·`[시장]` 참고 목록에
    따로(최대 3건). 직접 근거가 없으면 "현재 확인된 자료만으로는 ○○의 개별적인 하락 원인을 특정하기 어렵습니다".
  - LLM 경로: 원인 질문이면 기사마다 `관련성`을 붙여 넘기고, 답을 만든 뒤 직접 근거가 없으면 원인 절을 안내로, 근거 절을 코드가 만든 참고 목록으로 바꾼다.
  - `routing._PRICE_MOVE_RE`에 약세·강세(약세장·강세장 제외)를 넣어 이런 질문도 코드 원인 경로로 간다.

## 2. 종목만 바꾼 후속 질문

- 원인: "삼성전자 최근 20거래일 수익률 분석해 줘." 다음 "SK하이닉스는?"이 LLM 경로로 가서 news_tool만 불렀다(수익률 미계산, 삼성전자 기사 혼입).
- 수정: `app/followup_subject.py`. 후속 질문이 "종목 이름 + 조사·연결어"뿐이면(영어 What about, 일본어 は, 중국어 呢 포함) 직전 질문의 종목 자리만
  새 종목으로 바꾼 질문을 직전 대화 없이 처음부터 처리한다. 직전 질문도 이런 후속 질문이면 같은 사용자의 앞 리포트로 최대 3번 거슬러 간다.
  모델이 직전 종목을 도구 인자로 넣으면 새 종목으로 바꾼다. 기간·의도 낱말이 있으면(전망·뉴스·왜·5거래일) 새 질문이 우선이다.
  내부 메타 `subject_swap`에 바꾼 질문을 남긴다(API 응답 필드 아님). `resolved_instruments`의 source는 explicit이다.

## 3. 영어·일본어·중국어 화면의 한국어 원문 제목

- 출처 카드(`frontend/src/components/SourceFootnotes.tsx`): 한국어가 아닌 화면에서 한글 제목이면 "Original Korean headline"(ja·zh 같은 뜻)과
  "원문 언어 그대로" 안내를 붙이고 `lang="ko"`를 단다. 한국어 화면·한글 없는 제목은 그대로. 제목·링크·번호는 바꾸지 않는다.
- 번역 실패 요약의 제목 머리말: "original Korean headlines (shown in the source language)".
- 번역 검증에 번역 머리말 검사 추가("Here is the translation…", "以下は翻訳…"): 실측에서 이 머리말이 `translated`로 통과했다.

## 4. 번역 검증 실패 시 정량 결과 유지

- 원인: 기간 원인 답의 stock_tool 기록에는 prices가 없어 `fallback_summary`가 기사 제목만 남겼다(−7.62%·기간·지수 비교가 사라짐).
- 수정: `quote_i18n.fallback_summary`가 도구 기록에 이미 있는 값만으로 기간 등락(시작·끝 종가), 종가 최고·최저, 최근 5거래일, 지수 비교,
  끝나지 않은 기간 안내를 그 언어로 쓴다. 원인 답이면 "기사는 참고이며 직접 원인으로 확인된 것이 아니다", 직접 근거가 없으면 그 사실을 덧붙인다.
  검증되지 않은 LLM 번역은 여전히 내보내지 않는다.

## 5. 근거 없는 근거 절

- 출처가 없으면 `## 뉴스·공시 근거` 같은 근거 절을 지운다(자료가 없다고 밝힌 절은 남긴다). 원인 질문이면 "조회된 뉴스·공시 중 … 원인을 특정하지
  않았습니다" 한 줄을 붙인다(이미 밝혔으면 생략). "뉴스나 공시에서 이유를 찾을 수 있습니다" 같은 문장은 `strip_generic`이 지운다.

## 남은 점

- 기사 범위 판정은 제목·본문 요약(약 125자) 규칙이다. 본문 요약에 없는 맥락은 모른다. 애매하면 직접 근거가 아닌 쪽으로 둔다.
- LLM 경로에서 직접 기사와 업종 기사가 함께 있으면 답 문장은 모델이 쓴다(관련성 표시는 넘기지만 문장 단위 검사는 하지 않는다).
- 영어 뉴스 질문("Show me recent news about SK hynix")의 LLM 답은 기사 한 건 요약 수준이다(이번 범위 밖).
