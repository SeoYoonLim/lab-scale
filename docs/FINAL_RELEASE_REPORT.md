1. **공시 목록 항목이 번호만 남음**(`9af6943`). "그럼 최근 공시는?" 답이 "3. 동일인등출자계열회사와의상품ㆍ용역거래변경 / 4. / 5."로 나왔다. 실제로는 제목·날짜가 같고 접수번호가 다른 공시 3건이다. 원인: `answer_tidy.drop_repeats`가 "4. 제목"을 마침표 뒤 공백에서 "4."와 "제목" 두 문장으로 나눴고, "제목"을 앞 문장의 반복으로 보고 지웠다. 수정: 목록 표시를 떼고 본문만 문장으로 나눈다. 번호 목록 항목끼리 같은 문장은 다른 항목으로 보고 남긴다. 앞 산문을 되풀이한 문장은 전처럼 지우고, 본문이 다 지워진 목록 줄은 표시도 남기지 않는다. 수정 뒤 같은 질문의 답에 빈 번호 줄이 없음을 확인했다.
2. **기록 목록 요약에 `##`가 보임**(`4fa99f8`). 백엔드 `summary`는 답 본문의 공백만 정리해 자른 값이다. 이미 저장된 기록에도 적용되도록 프런트에서 제목·강조·코드·인용 기호만 뗀다. 수정 뒤 PC·모바일 기록 화면에 `##` 0건.
