남은 한계(오류는 아니지만 시연 때 알아야 할 것):

1. **"5일 수익률"은 달력 5일로 읽는다.** "삼성전자 5일 수익률은?"과 영어 "5-day return"은 2거래일 -7.62%로 답한다(답에 "2거래일간"이라고 밝힘). "최근 5거래일"이라고 물으면 -4.32%다. 이 규칙은 고정 평가 문항 `rt_26`("최근 20일 수익률은?" → 달력 기간)으로 정한 기존 설계라 이번에 바꾸지 않았다. "N일 수익률"(앞에 '최근'이 없는 지표 표현)을 거래일 창으로 볼지는 제품 판단이 필요하다.
2. LLM 경로 문장이 어색할 수 있다(예: "원인에 대해 자세한 분석은 없습니다"). 수치는 도구 결과만 쓴다.
