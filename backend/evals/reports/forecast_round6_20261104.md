## 6. 신호 묶음과 근거의 일관성

- 근거는 `group_evidence` 한 곳에서 묶음 판정(`group_votes`)과 같은 원천으로 만든다. 개별 신호를 다시 합산하지 않는다. SAME_FACT_AS(교차 ↔ 이동평균 배열)는 그대로다.
- SK하이닉스: 상승 근거 = [단기 흐름](5거래일 +2.91%, 코스피 대비 +2.92%p, 같은 묶음의 반대 신호: 종가 < 5일선)·[MACD], 하락 쪽 묶음 없음,
  엇갈린 묶음 = [중기 추세](5일선 > 20일선·골든크로스(상승)지만 종가 < 20일선(하락)이라 중립), 추세 참고 = 20거래일 -23.24%·60거래일 -10.34%·종가 < 60일선.
- 자동 검사(`tests/test_outlook_round26.py`): 상승 근거는 상승 묶음에서만, 하락 위험은 하락 묶음에서만, 중립 묶음의 상승 지표(골든크로스)는 상승 근거로 서지 않음,
  골든크로스는 한 번만, 상승 근거 수 = 상승 묶음 수(2)이고 개별 상승 신호 수(5)와 다름, 간결·상세 근거가 같은 함수 결과와 일치.
  평가(`check_evidence26`): 상세 답은 판정 상세의 묶음 줄로 대조, 간결 답은 묶음 비중 안에서 서로 다른 묶음 수. 통합 테스트로 실제 DB 두 종목의 간결·상세 일치.

- 표시 규칙: 공시 = DART 접수번호 날짜(같은 공시는 종합 판단·뉴스·공시·실적 어디서나 같은 날짜), 뉴스 = 한국 시간 발행일, 거래소 잠정실적 = "접수·발표일"(접수가 곧 발표), 정기보고서 = "접수일".
  뉴스 발행일·공시 접수일·실적 발표일·답변 생성 시각·시세 기준일은 서로 대신 쓰지 않는다.

- 직접·간접 뉴스 중복: 간접 뉴스는 직접 뉴스 URL을 빼고 고른다(기존 `exclude_urls`). 같은 URL이 여러 종목에 저장된 2,518건은 종목별 행이라 한 답변에 두 번 나오지 않는다.
